Container Apps Infrastructure Requirements
==========================================

Issue: Container App Environment deployment failed because the subnet needs to be delegated to Microsoft.App/environments

Current State:
- snet-function-apps is delegated to Microsoft.Web/serverFarms (for Function Apps)
- Container Apps cannot share the same subnet delegation

Requirements:
1. Create a new subnet specifically for Container Apps
2. Delegate the new subnet to Microsoft.App/environments
3. Update the Container App Environment configuration to use the new subnet

Options:
A) Create a new subnet in the existing VNet with delegation
B) Use an existing unused subnet and update its delegation

Recommended Solution:
Create a new subnet "snet-container-apps" with:
- Address space: /23 (minimum for Container Apps Consumption plan - 512 IPs)
- Delegation: Microsoft.App/environments
- NSG: Same as function apps or dedicated
- Route table: Same as function apps

IMPORTANT: Container Apps Consumption plan requires minimum /23 subnet!

Commands to Execute:
1. Check VNet address space: az network vnet show --resource-group appALZ-adcb --name vnet-adcb-dev-uaenorth --query "addressSpace"
2. List existing subnets: az network vnet subnet list --resource-group appALZ-adcb --vnet-name vnet-adcb-dev-uaenorth
3. Create new subnet: az network vnet subnet create --resource-group appALZ-adcb --vnet-name vnet-adcb-dev-uaenorth --name snet-container-apps --address-prefixes 10.0.4.0/23 --delegations Microsoft.App/environments
4. Update terraform configuration to use new subnet
5. Re-run terraform apply

✅ COMPLETED:
- VNet Address Space: 10.0.0.0/16
- Existing Subnets:
  * snet-privatelink: 10.0.1.0/24
  * snet-function-apps: 10.0.2.0/24 (delegated to Microsoft.Web/serverFarms)
- New Subnet Created: snet-container-apps: 10.0.4.0/23 (delegated to Microsoft.App/environments)
- Terraform configuration updated to use snet-container-apps
